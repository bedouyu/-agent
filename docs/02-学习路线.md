# 边做边学路线

## 第一阶段：读懂现在的代码

推荐按以下顺序阅读：

1. `backend/src/main/resources/application.yml`：理解 Java 如何连接本地 H2。
2. `PaperProject`：理解 Java 对象如何映射到数据表。
3. `PaperProjectRepository`：理解 JPA 如何省略基础 SQL。
4. `PaperProjectService`：理解业务逻辑和事务。
5. `PaperProjectController`：理解 HTTP API。
6. `PaperProjectApiClient.cs`：理解客户端如何调用 API。
7. `MainViewModel.cs` 和 `MainWindow.xaml`：理解 MVVM 数据绑定。
8. `DocumentStorageService`：理解 ZIP 安全解压和工作区路径检查。
9. `LatexCompileService`：理解 Java 如何安全调用 `latexmk`、Ghostscript 和 `synctex`。
10. `DeepSeekService`：理解环境变量、HTTP 请求、JSON 响应和超时处理；测试使用本机模拟服务，不消耗模型额度。

## 建议的练习

- 给项目增加“论文作者”字段，体验一次完整的数据库到界面修改。
- 增加删除项目接口，并在界面添加删除按钮。
- 在服务层禁止创建重名项目，并为规则补充单元测试。
- 在编译按钮旁增加“清理辅助文件”，调用 `latexmk -c`。
- 给源码区增加行号显示，并保持 SyncTeX 跳转准确。
- 给 AI 建议增加“接受/拒绝”按钮：先保存新版本，再展示差异，切勿覆盖上传的原稿。

## 调试原则

一次只验证一层：先用浏览器确认健康接口，再验证 API，然后运行桌面端。后端日志会显示在启动窗口中；如果使用脚本后台启动，则查看 `data/local-backend.log`。
